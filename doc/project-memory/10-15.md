## 미니미 시안 작업

- 참고 사진의 도트 질감을 바탕으로 편한 옷차림의 정지 모습·걷기 프레임 시안 제작 시작.
- Imagegen 내장 이미지 생성 도구 사용. 투명 배경, 동일한 캐릭터 외형을 유지하는 한 장의 시안 시트로 제작.

- 시안 제작 단계로 진행하며 현재 웹페이지의 미니미·미니룸은 교체하지 않음.

## 새로 확인한 콘텐츠 의도

- `기록은 조금 더 나답게.`: 개인 공간의 방향.

- `다이어리`: 사이드 개발 과정의 사건·고민·배운 점을 저장하는 블로그형 공간.

- 투명 배경. 글자·그리드선·소품·방·벡터처럼 매끈한 외곽선·흐림·그림자 배경 제외.

## 방 이동 후속 요구사항

- 미니미가 문으로 걸어가 문을 열고 다른 방으로 이동하는 구조.
- 이동 가능한 방 중 코딩방 포함. 위 장비 구성과 통유리 풍경 유지.
- 구현 시 배경·문·가구·캐릭터를 별도 레이어로 구성하고, 가구 충돌 영역 및 방별 입장 위치를 관리해야 함.
- 실제 게임용 캐릭터 프레임 정렬·문 애니메이션·방 전환·가구 상호작용은 아직 미구현.

## 움직이는 미니룸 적용

- 검정 후드티 미니미를 실제 `/minihome#miniroom`에 적용. 정지 4방향·걷기 6프레임을 공통 배율·발 기준선으로 정렬한 아틀라스 생성(왼쪽 걷기는 좌우 반전).
- 코딩방 v2에 소파 앞 LG 스탠바이미형 이동식 화면, 원통형 LG 공기청정기형 가전, 두 책상 사이 맥주용 미니냉장고 추가.
- 코딩방과 연결된 작은 휴식방 생성. 두 방의 닫힘/열림 문 이미지를 준비하고 열린 문 영역만 패치로 분리.
- 바닥 클릭/탭→가구를 피하는 경로 탐색→걷기. 문 클릭→문 앞으로 이동→문 열림→다음 방 입장, 반대 문으로 복귀 가능.
- 연속 클릭은 최신 목표로 이동 경로 변경. 방향키·이동 버튼, 불러오기 실패 시 재시도, 모션 감소 설정 지원. 드래그/스크롤은 이동 탭으로 처리하지 않음.
- 미니미 이동은 프레임별 DOM transform으로 그리며, 정지 상태에는 animation frame 루프를 멈춤. 이미지 배경·문 패치·가전/소파 가림 레이어·캐릭터를 분리.
- 모바일에서 같은 메뉴를 다시 눌러도 해당 섹션으로 이동하도록 미니홈 내부 메뉴를 기본 앵커 링크로 조정.
- 원본 홈 및 보류 중인 DB/느낌·다이어리·방명록 저장 기능은 변경하지 않음.

## 앉는 위치와 침대 앞 가림 수정

- 사용자 화면에서 의자 등받이/소파 위에 걸터앉는 배치 확인. 앉은 자세를 발 좌표 대신 자세별 엉덩이 앵커로 정렬하고 실제 좌판·안쪽 쿠션으로 이동.
- 코딩 의자는 모니터 쪽을 향하는 자세로 수정. 코딩·게임 의자의 등받이/팔걸이와 소파 앞부분을 별도 가림 레이어로 분리.
- 침대 앞에서 방향키 사용 시 발만 보이는 문제: 침대 묶음에 고정 Y 깊이를 사용해 앞 바닥의 캐릭터까지 가리는 것이 원인.
- 침대/벤치 앞 경계의 기울기를 X 위치별로 계산해 가림 순서를 갱신하고, 벤치 다리 앞쪽 충돌 영역 보강.
- 회귀 검사 추가: 앞 바닥에서 전체 미니미가 앞에 그려지는지, 위 방향 이동이 침대/벤치로 들어가지 않는지 확인. 테스트 8개·린트·프로덕션 빌드 통과.
- 사용 중인 탭과 검증 동작이 겹치지 않도록 이후 브라우저 검증은 별도 임시 탭에서 진행.

### 고양이 급격한 이동·산책 정지 수정

- 원인: 가구 접근/퇴장 거리에 관계없이 800ms(캣타워 950ms)로 보간했고, 이동 중 정지 자세를 써서 날아가는 것처럼 보임. 상대 고양이 장애물의 여유 폭도 실제 최소 간격보다 작아 같은 막힌 경로를 반복할 수 있었음.
- 가구 전환도 거리/85px·초 기준의 일정 속도로 이동하고 걷기 프레임 사용. 캣타워는 바닥→중간 발판→위 발판으로 단계 이동하며 작은 점프만 적용.
- 우회 장애물 여유 폭 확대. 근접 충돌이 지속되면 짧게 뒤로/옆으로 물러나 공간을 확보. 막힌 상태 이름표는 `산책` 대신 `대기`.
- `LoftCats.tsx` 대상 ESLint 통과. 테스트·브라우저 동작 검증은 실행하지 않음.

### 코딩방 가구 이동 속도 수정

- 코딩 의자·게임 의자·소파의 앉기/일어나기 이동이 거리에 무관하게 300ms로 처리되어 빠르게 날아가는 원인 확인.
- 이동 거리에 따라 시간을 계산하고 완만한 출발/도착 곡선을 적용. 전환 중 최대 이동 속도가 일반 걷기 속도를 넘지 않도록 조정. 같은 가구 이동 로직을 쓰는 침실 좌석에도 적용.
- 동작 감소 설정 유지. 브라우저 동작 검증·테스트는 실행하지 않음.

### 코딩방 자세 전환 재수정·전체 작업 커밋 준비

- 직전 거리 기준 보간은 발 기준 바닥 좌표와 엉덩이 기준 좌석 좌표 사이를 이동시켜, 앉은 자세로 공중을 미끄러지는 문제를 더 길게 보여줌.
- 가구까지의 걷기와 좌석 자세 전환 분리. 바닥 접근점까지 충돌을 피해 걷고, 240ms 동안 짧게 페이드하며 바닥/좌석 두 위치 사이에서 자세 변경. 중간 공중 좌표를 생성하지 않음. 일어나기도 역순 적용.
- 전환 진행률을 한 프레임 값으로 공유해 좌표·자세·투명도 동기화.
- 별도 브라우저 탭에서 코딩 의자→게임 의자→소파 앉기/이동 확인. [확인 화면](assets/10-15/coding-seat-transition-fixed.jpg).
- 기존 회귀 검사에서 침실 의자를 옮긴 자리를 빈 러그로 가정하던 좌표를 현재 빈 러그 위치로 갱신. 회귀 8개 통과, 전체 ESLint·TypeScript 검사 통과.
- 사용자 요청에 따라 지금까지 미니홈·미니룸·고양이·포트폴리오 갤러리·자산·스크립트·작업 기록을 함께 커밋/푸시. IDE 자동 생성 파일은 작업 산출물에서 제외.
- 최종 프로덕션 빌드 통과: 31개 페이지 생성 완료.
