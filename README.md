# 김민섭 개인 포트폴리오

Next.js, TypeScript, Tailwind CSS, App Router 기반의 1페이지 포트폴리오 1차 버전입니다.

## 실행

```bash
npm install
npm run dev
```

## 링크 교체 위치

- 이력서 PDF/DOCX: `src/data/portfolio.ts`의 `resumeLinks`
- 이메일/GitHub: `src/data/portfolio.ts`의 `contactLinks`
- 프로젝트 상세 확장: `src/data/portfolio.ts`의 `featuredProjects[].slug`

현재 실제 링크가 없는 항목은 placeholder로 남겨두었습니다.
