# 2026-10-28 작업 로그

## 타로 사업 기획 목표와 제작 상태 확인

- 배경: 대표 사이트·타로·마음결의 사업 방향을 논의하는 과정에서, 사용자가 석가머니 참고 화면 13장과 기존 타로 설계의 아쉬운 점을 제공했다.
- 사용자 확인 사항: 단기 목표는 한 달 안에 첫 유료 고객 확보. 156장면은 완성된 상태가 아니며 v5 기준으로 카드 제작 중이다. 기존 설계에서 타로다운 재미가 부족하고, 카드 속 상황 설명과 리더 캐릭터 설명을 결합하는 방식에 긍정적이다.
- 기획 기준: 참고 앱을 복제하지 않고 유입·상호작용·재방문을 유도하는 요소를 탐색한다. 현재 단계는 아이디어 개선이며 화면 구현 승인은 아니다.
- 실제 확인: 첨부 화면에서 채팅 시작 문구·추천 질문, 목탁·염주 조작, 꾸미기, 걸음 보상, 초대 코드, 20만 기념 이벤트를 확인했다. 공식 Google Play 소개에서도 목탁·염주·걸음·꾸미기 설명을 확인했다. 광고비 0원·한 달 내 사용자 20만이라는 성장 수치와 인과관계는 독립 검증하지 못했다.
- 남은 일: 첫 고객의 구체적 고민, 첫 상품과 가격, 무료·유료 경계, 유입 경로 및 제작 여력 결정. 제안하는 기능과 일정은 미확정이다.
- 서비스 코드 변경·빌드·동작 테스트는 수행하지 않았다.

## 타로 화면 IA v0.1 작성

- 요청: 논의한 기능을 화면 IA로 정리하고 폭포수 모델로 진행. 리더는 관리자 전용 수정, 사용자 아바타는 별도 존재이며 사용자가 직접 타로룸을 만든 뒤 친구를 초대해 방 안에서 실시간 채팅한다는 요구를 반영했다.
- 결과: [화면 IA 검토본](assets/tarot-screen-ia-v0.1.md)에 대표 사이트와 타로 서비스의 경계, 사용자·관리자 화면, 주요 이동, 빈 화면·실패 상태, 단계별 검토 기준을 작성했다. 기존 이력서 IA는 유지했다.
- 한국어·영어·일본어·중국어 기본 지원은 제안 상태로 반영하고 간체/번체 범위를 미정으로 표시했다. AI 동의·첫 튜토리얼·인스타 이벤트는 별도 공통 레이어로 구분했다.
- 실제 검증: 화면 ID 중복 및 문서 내 화면 참조의 정의 여부를 스크립트로 확인했고 모두 통과했다. 첨부 참고 화면의 구조를 요구사항과 대조했다. 실행 코드 변경, 빌드, 브라우저 동작 테스트 및 법률 검토는 하지 않았다.
- 남은 일: IA 검토·확정, 첫 출시 범위, 과금/회원/다국어/룸 운영 정책 결정 후 상세 화면 설계. 문서는 검토용이며 전체 기능의 첫 달 출시나 구현 승인을 의미하지 않는다.

## 대화 요약과 IA HTML 드라이브 업로드

- 요청에 따라 확정 요구와 미정 제안을 구분한 [사업기획 대화 요약](assets/사업기획%20대화%20요약%20v0.1.md), 메뉴 계층·이용 흐름·50개 화면·상세 원문을 담은 [IA HTML](assets/IA%20구조도%20초안%20v0.1.html)을 작성했다. HTML은 외부 의존성 없이 열리는 단일 파일이다.
- Google Drive의 지정 폴더 `3. 클로드_지피티로 창업도전`에 원래 확장자와 MIME 형식으로 두 파일을 업로드했다.
- 원격 파일: [요약 MD](https://drive.google.com/file/d/1L-ceVSiFE2A97KEkwXCmnPkwXklbZ-ps/view), [IA HTML](https://drive.google.com/file/d/1DLrbDHuhsNWr_gM8pu82wEMN-ijKE-fX/view).
- 실제 검증: HTML 50개 화면 수, ID 중복 없음, 내부 앵커 참조 모두 유효함을 스크립트로 확인. 업로드 후 메타데이터 재조회로 파일명·MIME·대상 폴더·크기를 확인했고 크기는 각각 로컬과 동일한 6,910/38,769바이트였다. 원격 체크섬은 반환되지 않아 바이트 완전 일치를 검증했다고 보지 않는다. 브라우저 시각 검증은 수행하지 않았다.
- 남은 일: IA 검토 및 상세 정책 결정. Drive에서 HTML이 실행되지 않으면 다운로드 후 브라우저로 연다.

## 타로 개발 프로젝트 분리와 현재 우선순위 확정

- 사용자 확인: 타로 서비스는 `my-resume`에서 구현하지 않고 추후 별도 프로젝트를 만들어 개발한다. 프로젝트명·경로는 아직 미정이며 이번 요청에서 새 프로젝트를 생성하지 않았다.
- 마음결은 기존 `maeum` 프로젝트가 있으며, 현재는 타로 기획에 더 집중한다.
- 이 저장소에 보관한 타로 요약·IA는 기획 기록일 뿐 이력서 서비스에 타로를 통합한다는 뜻이 아니다. 이후 구현 작업은 별도 프로젝트를 대상으로 한다.
- 검증: 사용자 지시와 기록 문구를 대조했다. 서비스 코드·프로젝트 구성 변경 및 실행 테스트는 없으며, 기존 Drive 산출물은 이번 요청에서 수정하지 않았다.
