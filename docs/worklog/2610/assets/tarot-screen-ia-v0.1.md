# 타로 서비스 화면 IA v0.1

작성일: 2026-10-28 (KST) · 상태: 검토용 초안 · 서비스명/도메인 미정

## 1. 목적과 문서 범위

한 달 안에 첫 유료 고객을 확보한다는 목표 아래, 타로 체험·결제와 재방문 공간의 전체 정보 구조를 정리한다. 이 문서는 화면 목록과 연결 구조이며 시각 디자인, 상세 정책, 출시 일정 확정 또는 구현 완료를 의미하지 않는다. 화면 ID는 문서 참조용이며 실제 URL은 상세 설계에서 정한다.

대표 사이트는 개인사업 소개·서비스 연결·포트폴리오·연락 창구로 두고, 타로와 마음결은 개별 서비스로 연결한다. 이번 상세 IA는 타로 서비스에 한정한다. 기존 이력서 IA 및 서비스 코드와는 별도 문서다.

## 2. 확정 요구와 초안 가정

### 사용자 확인 요구
- 카드 자산은 v5 제작 중이며 78종 × 정/역방향 156장면 전체가 완성된 상태가 아니다.
- 리더 캐릭터는 관리자만 수정한다. 사용자 아바타와 다른 존재다.
- 사용자마다 개인 아바타가 있으며 타로룸은 처음부터 생성되지 않는다.
- 사용자가 '내 타로룸 생성하기'를 누르면 방을 만들고, 친구를 초대해 입장한 사람끼리 채팅할 수 있다. 방 채팅을 방명록으로 대체하지 않는다.
- 첫 진입 튜토리얼, 첫 AI 전송 전 동의, 인스타그램으로 연결되는 이벤트 팝업을 포함한다.
- 폭포수 방식으로 IA부터 검토한다.

### 검토용 반영안
- 한국어·영어·일본어·중국어를 기본 지원 목표로 포함한다. 중국어 간체/번체 범위는 미정이다.
- 미리보기 몇 컷 후 전체 이야기 구매, 오늘의 운, 기록 공유, 아바타/룸 꾸미기, 염원 담기를 전체 IA에 포함한다. 가격·횟수·무료 컷 수·보상은 미정이다.
- 모바일 웹 우선 메뉴 구조를 제안한다. 웹/앱 출시 형태와 데스크톱 배치는 상세 설계 전 확정한다.
- 로그인 전 소개·튜토리얼·상품 탐색 가능, 구매·개인 기록·룸 생성·룸 채팅은 로그인 필요로 제안한다. 비회원 AI 미리보기 허용 범위는 미정이다.
- 기본 비공개 기록, 초대받은 사람만 방 입장, 친구 대화의 AI 자동 전송 없음으로 제안한다.

## 3. 전체 계층

대표 사이트: 소개 / 타로 서비스 / 마음결 서비스 / 포트폴리오 / 연락

타로 서비스 상시 메뉴 제안:
- 홈: 관심 질문, 오늘의 운 진입, 진행 중 이야기, 이벤트 배너
- 타로: 주제/질문, 리더, 사연 대화, 카드 선택, 미리보기, 구매, 전체 리딩
- 내 타로룸: 미생성 안내 또는 내 방, 꾸미기, 초대, 방문, 방 채팅, 염원
- 기록: 리딩 기록, 오늘의 운 기록, 공유 관리
- 마이: 내 아바타, 구매 내역, 설정 및 지원

공통 레이어: 로그인, 튜토리얼, AI 동의, 이벤트 팝업, 오류/확인 안내.
오늘의 운은 홈에서 바로 접근한다. 염원은 내 타로룸 안의 장소로 제안하며, 미생성 사용자는 방 생성 안내를 거친다. 룸 생성 없이 염원을 허용할지는 미정이다.

## 5. 관리자 IA

일반 사용자 메뉴와 분리한다. 화면 접근뿐 아니라 실제 변경 권한도 관리자에게만 둔다.

| ID | 화면 | 주요 관리 내용 |
|---|---|---|
| ADM-01 | 관리자 진입 | 인증·권한 확인 |
| ADM-02 | 리더 관리 | 이름·외형·소개·말투·공개 상태, 언어별 내용 |
| ADM-03 | 카드/장면 관리 | 카드 ID, 정/역방향, v5 등 버전, 제작/검수/공개 상태 |
| ADM-04 | 상품/리딩 구성 | 미리보기·전체 분량, 가격, 후속 대화 범위 |
| ADM-05 | 튜토리얼/이벤트 | 언어별 내용, 기간, 노출 조건, 인스타 목적지 |
| ADM-06 | 주문/문의 | 결제 상태, 실패·환불 문의 처리 |
| ADM-07 | 신고/룸 운영 | 신고 처리, 이용 제한과 조치 기록 |
| ADM-08 | 동의/안내 문서 | 항목·버전·시행일, FAQ, 개인정보 안내 |

미완성 카드가 완성된 것처럼 노출되지 않도록 공개 상태를 관리한다. 실제 추첨 가능한 덱 범위는 상세 설계에서 확정한다.

## 6. 주요 사용자 흐름

1. 첫 방문: HOME-01 → COM-01(완료/건너뛰기) → HOME-01. 질문/룸 초대 링크로 들어온 경우 목적지를 보존한다.
2. 유료 리딩: TAR-01 → TAR-02 → TAR-03 → COM-03(필요 시) → TAR-04 → TAR-05 → TAR-06 → COM-04(필요 시) → PAY-01 → TAR-07 → TAR-08.
3. 룸 생성: ROOM-01 → COM-04(필요 시) → ROOM-02 → ROOM-03 → ROOM-05.
4. 친구 방문: 초대 링크 → ROOM-06 → COM-04(필요 시) → ROOM-03 → ROOM-07. 방문자에게 자기 방 생성을 강제하지 않는 안이다.
5. 공유: REC-01 → REC-02 → REC-03 → 사용자 확정 → REC-04. 링크 철회는 REC-02에서 제공한다.
6. 동의 관리: SET-06 → SET-07 → 항목 상세 → 철회 확인 → 이후 AI 기능 진입 시 COM-03. 과거 데이터 삭제는 SET-08에서 별도 처리한다.
7. 이벤트: HOME-01 → COM-02 → 인스타 외부 이동. 닫으면 홈, 복귀 시 기존 서비스 상태 유지. 계정 URL은 아직 미정이다.

## 7. 공통 레이어와 상태 규칙 제안

### 튜토리얼·이벤트
- 튜토리얼은 다음/이전/건너뛰기/시작을 제공하고 설정에서 재열람한다.
- 첫 방문 튜토리얼과 이벤트를 겹쳐 띄우지 않는다. 초대 입장·카드 선택·결제 중에는 이벤트 팝업을 끼워 넣지 않는다.
- 이벤트는 닫기/다시 보지 않기/인스타 링크를 제공한다. 숨김 범위는 이벤트별이며 기간 정책은 미정이다.
- 튜토리얼 완료 상태를 기기/계정 중 어디에 저장할지 결정이 필요하다.

### AI 동의
- 참조 화면의 바텀시트 구조와 항목별 '보기', '나중에'를 참고한다. 경쟁 앱의 업체명·국가·학습 이용 문구를 그대로 복사하지 않는다.
- 실제 전송 대상·목적·데이터·처리 방식에 맞춰 동의 항목과 문서를 확정해야 한다. 현재 문서는 법적 적합성을 판정하지 않는다.
- 전송 전 필요한 동의의 유효 버전을 확인하고, 처음/철회 후/필요한 내용 변경 시 해당 흐름을 제공한다.
- 선택 항목이 있다면 거부해도 기본 이용이 가능하도록 분리한다. 선택적 학습 이용 자체는 도입 미정이다.
- 거절/닫기 시 AI 요청은 전송하지 않으며 입력을 보존한 채 돌아간다. 친구 간 채팅 동의를 AI 동의와 혼합하지 않는다.

### 결제·생성·기록
- 결제 전에 전체 가격/제공 범위/무료 범위를 표시한다. 미리보기와 구매 후 카드가 바뀌지 않는다.
- 결제 확인 중, 취소, 실패, 결제 성공 후 생성 실패, 재접속, 이미 구매함 상태를 설계한다. 재시도에 추가 결제를 요구하지 않는 안이다.
- AI 대기/실패/취소, 기록 없음/삭제됨, 공유 철회됨 상태를 제공한다.
- 언어 변경으로 과거 리딩을 자동 재생성하거나 재과금하지 않는다. 재번역 제공 여부는 미정이다.

### 타로룸·아바타·소통
- 리더는 서비스의 안내 캐릭터, 아바타는 이용자의 표현, 룸은 이용자가 만드는 방문 공간으로 분리한다.
- 방 생성 실패/저장 실패, 초대 만료/철회/잘못된 링크, 삭제된 방, 차단/내보내짐, 정원 초과, 채팅 연결 끊김/전송 실패 상태를 설계한다.
- 방 방문 권한은 개인 리딩·사연·구매·염원 열람 권한을 뜻하지 않는다.
- 방 삭제/탈퇴 시 초대 링크, 채팅 및 소품의 처리 정책은 상세 설계에서 결정한다.
- 실시간 채팅은 전체 IA 요구에 포함하며 출시 차수는 별도 합의한다. 자동번역/1:1 DM/공개 방 탐색은 현재 확정 범위가 아니다.

## 8. 다국어 범위 제안

4개 언어를 기본 지원 목표로 두되 UI 번역만으로 완료 처리하지 않는다. 메뉴, 튜토리얼, 이벤트, 카드명, 리더 소개, 리딩, 오류, 결제 및 동의 안내, FAQ를 검토 대상으로 둔다. 이미지에 대사를 고정 삽입하지 않고 언어별 텍스트를 분리한다.

미정: 중국어 간체/번체, 최초 언어 결정/대체 언어, 리딩 언어와 표시 언어 분리 여부, 기존 기록 재번역, 이벤트 번역 누락 시 노출 방식. 4개 언어 제공이 곧 해외 결제·모든 국가 출시를 뜻하지 않는다.

## 9. 폭포수 진행 단계와 완료 기준

| 단계 | 산출물 | 다음 단계 진입 기준 |

## 11. 검토 기준

- 모든 주요 화면에 진입점/다음 이동 또는 닫기·복귀 경로가 있는가.
- 리더 수정/사용자 아바타 수정/방 소유자와 방문자의 권한이 구분되는가.
- 방이 없는 초기 상태와 직접 생성, 친구 초대·입장·실시간 채팅이 포함되는가.
- AI 동의 전 전송 방지와 철회 후 재진입 경로가 있는가.
- 무료 미리보기에서 결제·구매 권한·전체 리딩까지 연결되는가.
- 튜토리얼·이벤트·AI 동의를 서로 다른 진입 시점으로 구분하는가.
- 4개 언어와 미정 중국어 범위가 명시되는가.

검토 근거: 본 대화의 요구사항 및 사용자 제공 AI 동의/튜토리얼/이벤트 참고 이미지. 실제 서비스 동작 검증이나 법률 검토는 수행하지 않았다.
